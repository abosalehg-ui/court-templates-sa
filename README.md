## 📋 نظرة عامة

تطبيق ويب متكامل يوفر **أكثر من 550 نموذجاً وصيغة قضائية** جاهزة للاستخدام في المحاكم السعودية، مع مجموعة من **الحاسبات القضائية المتخصصة** والأدوات المساعدة. التطبيق يعمل بالكامل في المتصفح دون الحاجة لاتصال بالإنترنت.

### ✨ المميزات الرئيسية

- 📝 **مكتبة نماذج شاملة** - أكثر من 550 نموذجاً مصنفاً
- 🔍 **بحث سريع** - البحث في جميع النماذج بسهولة
- 🧮 **6 حاسبات قضائية** - أتعاب الخبرة، الميراث، تقدير الأضرار، الأضرار المرورية، مكافأة نهاية الخدمة، الديات والشجاج
- 🔢 **تفقيط الأرقام** - تحويل الأرقام إلى كتابة (11 عملة)
- ⭐ **المفضلة** - حفظ النماذج المستخدمة بكثرة
- 📜 **السجل** - الوصول السريع للنماذج الأخيرة
- 🌙 **الوضع الليلي** - راحة للعين
- 📱 **تصميم متجاوب** - يعمل على جميع الأجهزة
- 🖨️ **طباعة مباشرة** - طباعة النماذج بسهولة

## 🧮 الحاسبات القضائية

### 1️⃣ حاسبة أتعاب الخبرة 💼
توزيع أتعاب الخبير القضائي بين الأطراف حسب نسبة المسؤولية، مع حساب النسب تلقائياً من المبلغ المطلوب والمحكوم به.

### 2️⃣ حاسبة تقدير الأضرار ⚠️
احتساب قيمة التعويض المستحق بناءً على قيمة الضرر ونسبة المسؤولية، مع تفقيط النتيجة.

### 3️⃣ حاسبة الأضرار المرورية 🚗
جمع تقدير التلفيات والرسوم وأضرار شحن المركبة في مجموع كلي مع التفقيط.

### 4️⃣ حاسبة الديات والشجاج 📜
حاسبة تفاعلية تشمل **193 عضواً ومنفعةً وشجة** من جدول مقادير الديات، مع:
- خيار الجنس (رجل / امرأة)
- نوع الجناية (عمد وشبهه / خطأ)
- وحدة الدية (ريال / إبل)
- بحث فوري وتفقيط تلقائي للنتائج

> **المصدر:** الأمر السامي رقم 43108 وتاريخ 2/10/1432هـ، والمبني على قرار الهيئة العامة للمحكمة العليا رقم (2) في 14/7/1431هـ.

### 6️⃣ حاسبة المواريث 📊
حساب التركات وفق الشريعة الإسلامية.

## 🚀 التشغيل والتنزيل

### الطريقة الأولى: استخدام Git (موصى بها) 🌟

```bash
# استنساخ المشروع
git clone https://github.com/abosalehg-ui/court-templates-sa.git

# الانتقال إلى مجلد المشروع
cd court-templates-sa

# افتح index.html في المتصفح مباشرة
# أو شغّل خادماً محلياً (اختياري):
python -m http.server 8000
# ثم افتح: http://localhost:8000
```

### الطريقة الثانية: تنزيل مباشر 📥

1. اضغط على زر **Code** الأخضر في صفحة المخزن
2. اختر **Download ZIP**
3. فك ضغط الملف
4. افتح `index.html` في المتصفح

### الطريقة الثالثة: الاستخدام عبر الإنترنت 🌐

ادخل مباشرة على الرابط:  
[https://abosalehg-ui.github.io/court-templates-sa](https://abosalehg-ui.github.io/court-templates-sa)

### إضافة: أداة تحويل النماذج 🛠️

```bash
# تثبيت الاعتماديات (مرة واحدة)
pip install -r requirements.txt

# تشغيل أداة Python
python wordtotemplates.py
```

النسخ التنفيذية الجاهزة (EXE) تُنشر عبر صفحة  
[**GitHub Releases**](https://github.com/abosalehg-ui/court-templates-sa/releases)  
مع بصمة تحقق (SHA256) لكل إصدار — يُنصح بالتحميل منها حصراً بدل الروابط الخارجية.

## 📖 صيغة بيانات النماذج (للمساهمين)

ملف `data/templates.js` يعرّف كائن `templatesData`، مفاتيحه أسماء التصنيفات وقيمه مصفوفات نماذج:

```js
const templatesData = {
    "اسم التصنيف": [
        {
            "num": "1",              // رقم النموذج داخل التصنيف (نص) — يُستخدم مفتاحاً ثابتاً للمفضلة والسجل
            "keyword": "الاختصار",   // الكلمة المفتاحية المعروضة في الجدول
            "content": "نص النموذج" // المحتوى الكامل (يدعم أسطراً متعددة بـ \n)
        }
    ]
};
```

> ⚠️ حافظ على ثبات قيمة `num` عند تعديل النماذج القائمة؛ فمفضلة المستخدمين وسجلهم يعتمدان عليها.

## 🛠️ التقنيات المستخدمة

## 📄 هيكل المشروع

```
court-templates-sa/
├── index.html              # هيكل الصفحة الرئيسي
├── README.md               # هذا الملف
├── LICENSE                 # رخصة MIT
├── package.json            # سكربت الاختبارات (npm test)
├── requirements.txt        # اعتماديات أداة Python مثبتة الإصدارات
├── wordtotemplates.py      # أداة تحويل جداول الورد إلى بيانات JS
├── css/
│   ├── style.css           # التنسيقات
│   └── fonts.css           # تعريفات الخطوط المحلية
├── js/
│   ├── calc.js             # دوال الحساب الصافية (مواريث، نهاية خدمة، تفقيط)
```
